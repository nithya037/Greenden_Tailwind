# 🌿 Greenden – Plant Shopping Website

Greenden is a simple, responsive plant shopping website built using HTML and Tailwind CSS. This project was created as a practice project to learn HTML structure, Tailwind CSS utility classes, responsive layouts, and basic UI design.

## ✨ Features

- Responsive navigation bar
- Plant product cards with images and descriptions
- Product pricing with discount display
- Responsive grid layout
- Mobile-friendly product buttons
- Hover effects and smooth transitions
- Nature-inspired color palette

## 🛠️ Technologies Used

- HTML5
- Tailwind CSS 2.2.19
- Visual Studio Code

## 🚀 How to Run

1. Clone this repository:

   ```bash
   git clone <your-repository-url>
   ```

2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser, or use the Live Server extension.
4. Navigate through the website to explore the pages.

## 🎯 Learning Objectives

- Practice writing HTML elements and semantic structure.
- Learn Tailwind CSS utility classes.
- Understand responsive breakpoints such as `md:` and `lg:`.
- Create product cards using CSS Grid and Flexbox.
- Apply hover effects, spacing, borders, and typography.
